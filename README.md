## 🚀 Quick Start (Local Development)

### Prerequisites
- Node.js (v20+ recommended, tested on v24.19)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Vishuu77/omnicommerce-hub.git
cd omnicommerce-hub

# Install dependencies
npm install

# Configure environment variables (optional for AI Agent Sandbox)
cp .env.example .env

# Start the full-stack development server
npm run dev
```

The application will be live at:
- **Main Portfolio:** [http://localhost:3000/](http://localhost:3000/)
- **Customer Commerce Portal:** [http://localhost:3000/customer-portal.html](http://localhost:3000/customer-portal.html)
- **Employee Back-Office CRM:** [http://localhost:3000/employee-crm.html](http://localhost:3000/employee-crm.html)
